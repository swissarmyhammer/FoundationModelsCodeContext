## What
A `X.Name` query (Python `module.Class`) that finds no class `X` gives an empty result now, and its near candidates are wrong. Add a `module` match tier. It runs after `inherited` and before `caseInsensitive`. It splits the query on `.` into a module part and a symbol part, and matches each candidate whose qualified path is the symbol part and whose file path, with the extension removed, has the module part's segments as a contiguous run of path components. So the file stem matches (`startapp.py`, `startapp.swift`, `startapp.rs`) and so does a module directory (`startapp/__init__.py`, `Sources/startapp/x.swift`). Every split is tried, so `commands.startapp.Command` and `startapp.Command.handle` work too.
