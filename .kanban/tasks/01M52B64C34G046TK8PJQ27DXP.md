## What

The model (or a host) must be able to stop the language servers before a build cleanup, and start them again after the cleanup. A stopped server releases its file locks. This card adds two operations to the `code_index` tool. They call the engine API of the card "LSP stop and start ... (engine)": `CodeContext.stopLanguageServers()` and `CodeContext.startLanguageServers()`. The auto start and the auto install from project detection do not change.

### The approach

- [ ] Add `stopLanguageServers() async -> [ServerStatus]` and `startLanguageServers() async throws -> [ServerStatus]` to `CodeContextOperating` (`Sources/FoundationModelsCodeContext/Tools/CodeContextOperating.swift`), next to `lspStatus()`. `extension CodeContext: CodeContextOperating {}` then conforms with no more code.
- [ ] Add `Sources/FoundationModelsCodeContext/Tools/Index/StopLspOperation.swift`: `@Generable @Operation(verb: "stop", noun: "lsp", description: "Stop each language server of the workspace, so that it releases its file locks, for example before a build cleanup. The index continues to answer. Use `start lsp` to start the servers again.") internal struct StopLspOperation {}`. Its `execute(in:)` gives `ToolOutcome<[ServerStatus]>` through `ToolSupport.outcome { await context.operating.stopLanguageServers() }`. Copy the form of `GetLspStatusOperation.swift`.
- [ ] Add `Sources/FoundationModelsCodeContext/Tools/Index/StartLspOperation.swift`: `@Operation(verb: "start", noun: "lsp", description: "Start the language servers of the workspace again after `stop lsp`. The workspace detects its projects again and installs a missing server when the auto install is on.")`, with `try await context.operating.startLanguageServers()`.
- [ ] In `Sources/FoundationModelsCodeContext/Tools/Index/CodeIndexTool.swift`: add `AnyOperation(StopLspOperation.self)` and `AnyOperation(StartLspOperation.self)` after `GetLspStatusOperation` in `operations()`. Remove the noun alias `"lsp": "lsp_status"`, because `lsp` becomes a real noun (the doc comment of `nounAliases` says that no key is a real noun). Add the verb aliases `"shutdown": "stop"`, `"kill": "stop"`, `"launch": "start"`. Add the two ops to `description`.
- [ ] Update `docs/tools.md` (the op table, the "no parameter" line, the alias tables: remove the row `lsp` -> `lsp_status`, add the new verb aliases) and `README.md` (`code_index` (4) becomes (6)). Write all text in ASD-STE100 Simplified Technical English.
